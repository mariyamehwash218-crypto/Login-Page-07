# Login-Page-07
A simple login page made using HTML5 and CSS3.
About the Project

This is my seventh web development assignment. I created a simple login page using HTML and CSS.

Features

- Email input field
- Password input field
- Login button
- Centered login form
- Simple and clean design
- Required field validation

Technologies Used

- HTML5
- CSS3

Files

- "index.html" - Contains the login form structure.
- "style.css" - Contains the styling of the login page.

Concepts Used

- CSS Flexbox
- Margin and Padding
- Input Fields
- Form Elements
- Box Shadow
- Hover Effects

How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open index.html in your browser.

What I Learned

- Creating forms using HTML.
- Styling input fields and buttons.
- Centering elements using Flexbox.
- Using required field validation.
